# Groups and Missions
<!-- description -->Tutorials can be grouped into larger units called Groups and Missions.  Learn How.

## You will learn  
  - How to compose and request a Tutorial Mission or Group

## Note 
If you haven't already, you will want to consult with [Riley Rainey](mailto:riley.rainey@sap.com) or appropriate Developer Advocates. These folks can give you advice on how to effectively leverage Groups and Missions as part of your overall design.

---

### Important considerations

1. We do not want to delete missions and groups after we have created them, so the tutorials/groups/missions that you create should last a while -- years!

    - **Create only what will last and what you can support over the long haul.**

    - **Plan ahead, think in terms of a one to two year time horizon if possible**

    >Of course, you can update tutorials at any time, as well as add or subtract individual tutorials within a group/mission as your product evolves.

2. Create groups/missions that build things, that give a goal to the user.

    > You will need to assign the group/mission a title and that title should be worded as a goal statement. When composing it, **avoid superlatives or other marketing-oriented phrasing -** Describe the outcome as crisply as possible.

3. Each group/mission needs an icon. Make sure you have provided one for your technology/service/product.

### Prepare and send a description of the Groups/Missions

Send the following information for each Group and Mission you wish to have created. You can copy the table into an email.

|  Item       | Information needed
|  :------------- | :-------------
|  Title            |  The title to be associated with the Group or Mission (note, this must be a unique string)
|  Description           | Describe what the user will do or create in one or twp paragraphs. Focus on the task and avoid marketing terminology wherever you can.
|  Experience     | Select from: Beginner, Intermediate, or Advanced
|  Primary Tag            | A  single metadata tag identifying the main product or topic that's the subject of the Mission or Group. This will typically match the primary tag used in most of the component tutorials. If you are unfamiliar with tags, you can refer to [Big Picture Tutorial](/tutorials/docs-tutorial-0-big-picture-2022.html) for information about tags.
|  Secondary Tags     | These will generally be an aggregation of all the secondary tags referenced in the constituent tutorials.
|  Time to Complete  | Expected time to complete, expressed in minutes.  A solid guess would be to add the times for all tutorials.
|  SVG Icon (for Missions) | An icon that will accompany a Mission.  This will be displayed as part of the Tutorial Navigator tile describing the content. You can look at existing Missions to get an idea of the style.  This generally ought to be created by a professional designer.  Defaults icons are available.

Prepare an ordered list of the tutorials/groups in your group/mission. For each tutorial/group, provide:

  - Tutorial Title (Copy from the MD file)
  - URL (a QA URL is acceptable during the design process, however, the Tutorial(s) must be published
  to production prior to publishing Groups or Missions)

>Any specified tags must already be present in IMS. For more information, see ["Tags"](https://jam4.sapjam.com/groups/A7NmsKmoG9vVaxizKhdQOk/overview_page/qaqhwSll2Gk0r7KJnzxTCT).

Once you have prepared the email, send it to [Riley Rainey](mailto:riley.rainey@sap.com) for review and processing.
